# 图片与人像

图像优先级：用户本人照片和真实作品 → 与项目相关的截图、过程或结果 → 主题相关的辅助图片 → 少量氛围图片。不能用图库人像充当本人，不能用通用办公照片充当项目实物图。不要为了填满栏目随机配图。

## 从文档找到图片

在每次创建的网站版本目录内运行，不改原文件：

```sh
python3 -S /path/to/skill-website/scripts/media_tools.py inventory /path/to/resume.pdf /path/to/materials.docx /path/to/photo.jpg --out /absolute/run/work/media
```

输出 `media-manifest.json` 和 `assets/`，保留来源文档、PDF 页码/对象或 DOCX 内部文件名、图片尺寸、哈希和未能提取的内容。支持 JPEG 与常见 8-bit RGB/灰度 PDF 图像（含兼容透明蒙版），也遍历嵌套 Form；其他色彩空间、位深、受保护 PDF 等会明确报告。整页扫描图也会被提取，不能把它直接选为头像。Word 的常见位图直接提取，特殊格式需使用环境已有能力另行转换。

这是图片清单，不是人脸身份识别。逐张打开有可能是人像/作品的图片；确认来源和画面后才安排用途。若没有独立人像但原始页上明显有照片，使用可用的页面渲染和图像处理能力提取照片区域；不能把整页简历公开。如果当前工具无法可靠处理，说明具体缺项。

## 记录选用决定

```sh
python3 -S /path/to/skill-website/scripts/media_tools.py select /absolute/run/work/media/media-manifest.json --id image-实际ID --role portrait --reason '已查看：简历中的单人证件照，与用户要求一致' --usage-basis '用户提供并要求在个人网站使用' --focal 50 35
```

角色可为 `portrait`、`project`、`atmosphere`、`interest`。`--focal` 是头像/封面裁切时的横纵百分比焦点，保留原图。输出供选择图片使用，需补上准确的 `alt`；不要将选图输出原样写入页面数据。`credit` 和 `source_url` 默认留在素材清单，仅在需要公开署名时填入网站图片字段。

人像选择明确时直接使用；多张归属不明、合照或画质不够时，才问最小必要的问题。找不到本人照片时省略头像，不能生成或借用一个人冒充。低清图片使用较小预览，并记录清晰度限制。

## 图片说明与来源的展示

个人主页的氛围图默认只展示图片。不要自动添加“工作空间主题摄影”“氛围图”“图库素材”等制作说明、作者行或来源链接，也不要为这些文字保留空白占位。选图理由、作者、来源网址和使用依据保存在 `work/` 的素材清单中。

生成页面数据时，普通氛围图只填写 `file`、准确的 `alt` 和需要的 `position`，省略 `caption`、`credit`、`source_url`。渲染器会公开展示后面三个字段，因此不能把内部来源记录直接复制进页面数据。`alt` 继续描述实际画面，供辅助阅读使用。

以下情况按实际需要显示：用户明确要求的图片说明；有助于理解真实作品的名称、地点、时间或结果；素材许可或所用 API 要求的公开署名。必要署名简洁呈现，不能因为追求简洁而隐藏；若与用户的无署名设计要求冲突，优先换用适用的素材。不要一并删除有意义的项目图注、流程说明或作品标题。

## 头像交互

默认 `portrait_placement: "header"`，左上角约 52px 圆形头像，裁切只影响缩略图。桌面悬浮或键盘聚焦可预览，点击打开完整照片；手机点击打开。弹窗保留原比例、限制在视口内，支持关闭按钮、Escape、焦点恢复和遮罩关闭。无 JS 时仍能点击查看原图。可显式用 `hero` 或 `both` 调整位置。

首屏氛围图片单独使用 `hero_image`，不要因设置首屏图而漏掉头像，也不要把图片的装饰角色和本人身份混用。

## 外部素材与可选连接

不要求安装某一个 MCP，也不把任何 API Key 放入技能包或网站。优先复用客户端已有的图片搜索/图库连接；无连接时可浏览图库官方页面挑选允许使用的图片，记录作者、来源页、使用依据和日期。自动下载只在使用依据允许时进行，不能绕过图库的 API 或访问限制。

搜索前先确定用途、横竖比例、主体位置和色调；查看候选实际画面后再选用。同一页面的图片应有一致的色调或明确的叙事联系。外部图片在清单中注明 `source_url`、`credit`、`usage_basis`，必要署名进入页面，私有来源路径留在 `work/`。

如果用户要求接入 API/MCP，先检查当时的官方申请条件与使用要求，提供可替换的数据来源层。图库不可用时回到本地素材，不中断内容整理。Unsplash API 图片链接、署名和下载统计有专门要求，不能一概按“下载到离线包”处理；Pexels 等也应以当时官方规则为准。连接和密钥配置属于单独的环境准备，不在每次建站时重复安装。
